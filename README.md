# تطبيق درجاتي للأندرويد

تطبيق WebView باسم «درجاتي» يفتح موقع المدرسة الحالي ويتيح رفع الملفات من خلال منتقي ملفات أندرويد.

## بناء APK عبر GitHub Actions
1. أنشئ مستودع GitHub جديداً باسم `darajati-android`.
2. ارفع محتويات هذا المجلد كاملة إلى جذر المستودع، مع المجلد المخفي `.github`.
3. افتح تبويب **Actions** واسمح بتشغيل workflows إذا طلب GitHub ذلك.
4. اختر **Build Darajati APK** ثم **Run workflow**، أو انتظر حتى ينتهي التشغيل الذي يبدأ بعد رفع الملفات.
5. افتح عملية التشغيل الناجحة، وانزل إلى **Artifacts**، ثم نزّل `darajati-apk`.
6. فك ضغط الملف الذي نزّلته لتحصل على `app-debug.apk`، ثم افتحه على هاتف Android وثبّته.

## ملاحظات
- التطبيق يعرض الموقع المنشور على Railway؛ تحديث الموقع يظهر في التطبيق دون إعادة بناء APK.
- يجب أن يكون الموقع متاحاً على الإنترنت. رفع الملفات يعتمد أيضاً على عمل واجهة الرفع والخادم.
- هذه نسخة Debug للتجربة والتثبيت اليدوي، وليست نسخة موقّعة للنشر على Google Play.
